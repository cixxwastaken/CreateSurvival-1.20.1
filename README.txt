Create: Survival
================

Fresh survival-focused Create addon content.

New in this branch
------------------
- Added the **Clockwork Canteen**, a refillable Create-grade flask that tracks water purity, hydrates the Thirst mod, and displays sip capacity directly in its tooltip.
- Introduced **Steam-Packed Rations** and the **Steam Relief Canister**, pressure-sealed meals that restore hunger, heal in a pinch, and hydrate Thirst players while nudging Cold Sweat temperatures when available.
- Crafted the **Surveyor's Thermometer** and **Thermo Vest**, letting explorers read Cold Sweat's temperature data or fall back to vanilla biome cues while enjoying Create-flavored survival gear.

Each recipe is gated behind Create components so progression stays aligned with a mechanical survival experience.
