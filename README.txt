Create: Survival
================

Fresh survival-focused Create addon content.

New in this branch
------------------
- Added the **Clockwork Canteen**, a refillable Create-grade flask that tracks water purity, hydrates the Thirst mod, and displays sip capacity directly in its tooltip.
- Introduced **Steam-Packed Rations**, pressure-sealed meals that restore hunger, grant temporary resilience buffs, and hydrate Thirst players in a pinch.
- Built the **Mechanical Water Purifier**, a redstone/mechanical-powered workstation that boosts canteen purity tiers to keep automation-ready adventurers healthy.

Each recipe is gated behind Create components so progression stays aligned with a mechanical survival experience.
