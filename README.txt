Create: Survival
================

Fresh survival-focused Create addon content.

New in this branch
------------------
- Added the **Clockwork Canteen**, a refillable Create-grade flask that tracks water purity, hydrates through the new thirst system, and displays sip capacity directly in its tooltip.
- Introduced **Steam-Packed Rations** and the **Steam Relief Canister**, pressure-sealed meals that restore hunger, heal in a pinch, and interface with our bespoke hydration/temperature managers.
- Crafted the **Surveyor's Thermometer** and **Thermo Vest**, letting explorers read the internal survival telemetry while enjoying Create-flavored gear.

Each recipe is gated behind Create components so progression stays aligned with a mechanical survival experience.
